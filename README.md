# cloudflare-fullstack-framework skill


This skill should be used when scaffolding or building a fullstack web app on Cloudflare Workers with React Router v7 (SSR) + Hono API + D1/KV bindings, or when adding any of four production pillars to such a project: optional dual-mode login (anonymous signed-cookie session + optional Clerk JWT), SEO infrastructure (canonical URLs, legacy 301 redirects, robots.txt, dynamic sitemap.xml, JSON-LD), Cloudflare Workers deployment via wrangler, or payment integration via Creem. Also relevant when migrating an existing app to this stack.
